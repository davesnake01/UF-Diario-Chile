# 🇨🇱 UF Diario Chile

![Python](https://img.shields.io/badge/Python-3.8%2B-blue?style=flat-square&logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green.style=flat-square)

Herramienta ligera y eficiente desarrollada en Python para la consulta, extracción y procesamiento automatizado de los valores diarios de la **Unidad de Fomento (UF)** en Chile.

---

## 🚀 Características

* **Consulta Actualizada:** Obtención rápida del valor de la UF, dolar y plata para el día en curso directamente desde el Banco Central de Chile.
* **Procesamiento de Datos:** Estructuración de los datos listos para ser integrados en sistemas financieros, facturación o bases de datos.
* **Integración Sencilla:** Diseñado para ser utilizado como script independiente o importado en otros proyectos backend.
* **Bajo Consumo:** Optimizado para realizar peticiones rápidas y ligeras.
